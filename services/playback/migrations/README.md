# Playback session persistence

Migration 0001 is additive and owned solely by Playback. Compose's finite playback-init runs the guarded local migration CLI as the migration identity, never the runtime login. It uses a session advisory lock, applies an absent schema or verifies existing version 1, and creates/grants the restricted local login. An existing 0001 schema is not recreated. Runtime membership grants only the explicit Playback reads/inserts/deletes and the singleton row-lock column; no other context, migration or existing-session update permission. Readiness rejects incompatible schema or elevated/cross-owner grants.

[ADR-0027](../../../docs/adr/0027-local-playback-sessions.md) fixes local policy: 4096 total SQL-enforced slots, fifteen-minute maximum lifetime, rights-capped expiry, current two-second Catalog snapshot, anonymous profile only, and minimal audit correlation. In one bounded READ COMMITTED transaction, lock the singleton admission row, delete at most 64 records expired for at least 24 hours, choose one free slot and insert. No live/recent record is evicted. Full capacity fails explicitly. SQL rechecks expiry/freshness against database time; no network calls occur while holding the lock. Audit cleanup is creation-driven, not a background worker or unbounded delete.

The session identifier is not an object-storage credential. Expiry does not revoke open media or CDN caches. Runtime does not update stored session/publication bindings. An uncertain commit requires caller reconciliation/new user intent, never a blind mutation retry.

Normal rollback stops Playback and restores the previous Router artifact while retaining the new schema and all Catalog/media data. The down script removes only Playback's new schema/role but destroys its session audit: run only on an explicitly disposable database or separately authorized backed-up recovery target. It deliberately avoids CASCADE, so later dependencies block destructive rollback. Reapplying up after down is required integration evidence. Retained project volumes have not been migrated by these unit checks.
