- ADR-0047 records the three-second/eight-request public execution boundary,
  account-partitioned Identity admission, Redis degradation and mandatory
  GraphQL no-store policy.
- Operation demand manifest format version 2 classifies every exact current or
  retained operation as public/account/profile, assigns one finite rate class,
  and records deadline, concurrency and no-store. Exact name coverage and
  derived private scope fail composition.
- Router inserts Cache-Control: no-store on every public response.
- Identity create/update/delete use profile_mutation (burst 8, refill 2/s);
  selection uses profile_selection (burst 16, refill 4/s). Authorization runs
  before admission and repeats in the existing owner command before a write.
- Redis keys contain only SHA-256 account/admission pseudonyms, use finite TTL
  and atomic server-time token buckets, and never authorize durable state.
- PostgreSQL is Identity's sole readiness-critical dependency. Redis connects
  on demand, degrades to the bounded local shield and remains lifecycle-owned.
