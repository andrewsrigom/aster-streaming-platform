## Outcome

Provide usable local operator commands to create/edit metadata and rights, review, mark media ready, publish, retire, dispute and reopen titles. Serialize rights/publication decisions with audit and versioned outbox facts, reject viewer/forged authority, and replay duplicate commands safely. Public browse/schema and real-media integration remain separate Phase 03/06 requirements, not waived.

## Current behavior

Phases 00–02 are released. Catalog domain and rights persistence are committed at 12db9fb with 61 tests and real PostgreSQL proof. No operator command, metadata, publication store or Catalog endpoint exists.

## Proposed behavior

Accept ADR-0015 for the local operator boundary: an explicit local-only CLI whose in-process authority cannot be supplied by a JSON input, browser role or viewer JWT. Implement metadata/locale rules, editorial application commands and PostgreSQL migration 0002. Use the current adapter, immutable rights history, per-title locks, 24-hour receipts, audit and publish/retire outbox. Commands take publication IDs and resolve trusted owner-held publication attestations; never accept a caller's validated boolean.

## Boundaries

- Owner/data: Catalog schema; no Identity SQL, remote actor service, broker client or media proxy.
- Paths: services/catalog domain/application/infrastructure/transport, migrations/tests, command wiring and evidence.
- ADRs: 0002/0003/0004/0006/0007/0010/0013/0014; new local-operator decision 0015.
- Skills: agent, architecture, product, node-runtime, data-events, media-streaming, security, testing, documentation.
- Trust: CLI operator controls the local process; inputs cannot select actor, grant roles or register media attestations. Runtime cannot write the publication-validation table.
- No new external version. Database deadlines/cancellation and existing structured dependency telemetry remain.

## Invariants

- Default deny; recheck local authority before transaction success. No remote calls while locks are held.
- Exact bounded command shapes, expected title version, title-bound idempotency key/digest and actor.
- Create/edit use draft rights; only a complete compatible review can advance RIGHTS_REVIEWED.
- Every rights/status/metadata/lifecycle change is auditable and atomic with its receipt.
- Publication rechecks latest rights, expiry, title/revision/checksum/validation timing and selected publication.
- Dispute/expiry retires immediately, preserves immutable history, and writes a retirement outbox event.
- Up to 128 pending publication events/title, with the last slot reserved for retirement. Never evict pending events; publishing backpressures before takedown does.
- Metadata supports bounded localizations/credits/genres and optional independently attributed artwork. Locale fallback is deterministic.
- Rights approval is not invented by synthetic fixtures; trusted publication records in tests remain explicitly synthetic until P03-R04 fixture verification.
