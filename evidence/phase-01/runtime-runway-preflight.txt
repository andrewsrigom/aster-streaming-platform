Kafka client finding
--------------------

An isolated npm project installed @confluentinc/kafka-javascript 1.10.0 on Node.js 24.19.0. The installed tree contained 26 production packages and occupied approximately 38 MiB in that temporary npm layout. The high-severity audit reported zero known vulnerability. Loading the module and creating the KafkaJS-compatible producer succeeded.

An unreachable 127.0.0.1:1 connect was raced against a 250 ms preflight deadline with library logging disabled. The caller observed the deadline after 251 ms, but the process remained active while producer.disconnect() used the compatibility layer's fixed five-second native disconnect. Source inspection found that fixed timeout in lib/kafkajs/_producer.js. This is a compatibility observation, not a benchmark. P01-R07 must prove a shutdown path that fits the Aster lifecycle before this client can be selected.

KafkaJS 2.2.4 is much smaller and has no runtime dependency, but the registry reports its last modification on 2023-02-27. It remains a comparison candidate, not the safe default.
