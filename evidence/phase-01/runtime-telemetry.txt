Implemented contract
- Manual process-local reader when export.mode is none; instrument creation and collection require no network or Collector.
- Optional OTLP/HTTP exporter accepts only HTTP(S) endpoints without embedded credentials.
- Periodic export has explicit interval, timeout, one in-flight attempt, cardinality ceiling, and bounded batch size.
- HTTP route, method, dependency, operation, outcome, status-class, export-result, and drop-reason dimensions are finite.
- HTTP and dependency leases complete once and active counters cannot decrement twice.
- Caller IDs, URLs, query text, GraphQL documents, request/trace/span IDs, headers, errors, credentials, endpoints, buckets, and object keys are absent from metric attributes.
- Process CPU time is canonical. CPU utilization is derived from CPU-time delta divided by elapsed monotonic time and CPUs available to the process, then bounded from zero through one.
- Runtime observers stop before provider shutdown. Repeated and concurrent shutdown is idempotent and flush/shutdown results are sanitized.
- Export timeout/failure increments process-local attempt/drop health without reflecting endpoint or error details and without changing readiness or product work.

Metric names and units
- http.server.request.duration: seconds; official HTTP server boundaries 0.005 through 10 seconds.
- http.server.active_requests: requests.
- aster.dependency.operation.duration: seconds; explicit boundaries 0.001 through 10 seconds.
- aster.dependency.operation.active: operations.
- aster.dependency.operation.outcomes: operations.
- aster.telemetry.export.attempts: attempts.
- aster.telemetry.dropped_observations: observations.
- process.cpu.time: seconds, user/system modes.
- process.cpu.utilization: ratio, user/system modes.
- process.memory.usage: bytes, resident memory.
- process.uptime: seconds.
- Runtime instrumentation additionally supplies nodejs.eventloop.*, v8js.gc.duration, v8js.memory.heap.*, and v8js.resource.active.
