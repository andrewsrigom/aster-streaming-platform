IMPLEMENTED CONTROL
-------------------

The repository-owned validator has no additional package dependency and uses Node.js 24 platform modules. It scans checked-in Markdown below the resolved repository root without following symbolic links or fetching external URLs.

Bounded inputs:
- at most 1,000 Markdown documents;
- at most 1,000,000 bytes per document;
- at most 20,000,000 total Markdown bytes;
- at most 20 directory levels;
- at most 20,000 characters per line;
- at most 2,000 links and 500 headings per document;
- at most 200 diagnostics.

Validated behavior:
- fatal UTF-8 decoding;
- non-empty document and first top-level title;
- matching backtick or tilde fences;
- no unresolved merge markers;
- repository-relative local files and directories;
- local Markdown heading fragments;
- percent-decoded traversal, absolute Windows paths, file URLs, backslashes, and symbolic targets rejected;
- inline and reference-style Markdown destinations;
- high-confidence canonical Node.js, TypeScript, JavaScript, GitHub, GraphQL, DataLoader, microservice, WebSocket, and PostgreSQL terminology outside code;
- unqualified absolute maturity phrases rejected;
- implemented, verified, or released claims in Current status require a same-line checked-in evidence or current-state link.
