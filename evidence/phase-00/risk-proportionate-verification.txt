IMPLEMENTED CONTRACT
--------------------

- pnpm check and pnpm check:changed use one repository-owned canonical list of
  24 Turbo tasks.
- pnpm check preserves the existing complete repository graph.
- pnpm check:changed adds Turbo affected execution and fixes TURBO_SCM_BASE to
  main and TURBO_SCM_HEAD to HEAD, overwriting inherited caller values.
- Only one --changed and one --force flag are accepted. Unknown or repeated
  narrowing arguments fail before spawning Turbo. Windows invokes pnpm.cmd
  through a fixed cmd.exe /d /s /c boundary because command scripts are not
  directly executable there; every command argument remains repository-owned.
- Child execution has a 15-minute bound, preserves the selected nonzero status,
  and emits bounded errors without reflecting process or environment details.
  A timeout force-terminates the detached POSIX process group or the complete
  Windows process tree, with a five-second bounded close fallback.
- SIGINT and SIGTERM use the same process-tree termination path, remove both
  wrapper signal handlers, and return conventional statuses 130 and 143 with
  the same bounded close fallback.
- Task-input-aware affected selection is enabled. Root lint owns application,
  package, service, tool, and worker source; formatting owns Markdown; security
  scanning owns every changed repository file.
- Pull-request template duplicate suppression accepts only a non-symbolic
  case-insensitive alias of the canonical entry. A symbolic alternate path that
  resolves to the canonical template remains a file-set violation.
- Work plans now name iteration, candidate, heavyweight-repeat, and review-stop
  gates. The default review cadence is one complete review plus one confirmation.
