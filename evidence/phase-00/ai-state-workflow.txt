IMPLEMENTED CONTRACT
--------------------

The dependency-free tools/verify-ai-state.ts command reads ten fixed durable .ai files as regular, non-symbolic, bounded, strict UTF-8 inputs. It emits stable JSON and sorted diagnostics without echoing arbitrary file contents.

The structural contract verifies:
- the required repository-memory file set;
- a bounded canonical work-queue table;
- unique contiguous order and a completed prefix;
- READY, IN_PROGRESS, DONE, and explicit BLOCKED_BY_<order> status syntax;
- backward, existing, non-completed blocker references;
- at most one active item, located at the earliest unfinished order;
- an active plan with matching requirement, active phase, metadata, and every work-item template section;
- the canonical inactive plan when no item is active;
- an ISO current-state date and required current-state sections;
- active or first-ready requirement binding across current state and handoff;
- reverse-chronological session entries with Completed, Evidence, and Next action sections.

The check is intentionally structural. It does not claim to prove arbitrary narrative truth, infer whether every code change needs a state transition, or prove append-only history without comparing Git revisions.
