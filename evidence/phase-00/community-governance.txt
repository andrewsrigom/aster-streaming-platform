The prior internal draft pull-request template was removed so the active GitHub file is authoritative. Blank contributor issues are disabled. Labels, assignees, external contact links, private vulnerability reporting, and hosted rendering are not invented or claimed before remote governance.

The pull-request contract requires a requirement or defect, behavior, ownership and trust boundaries, failure and recovery behavior, security and privacy impact, data and migration impact, observability, tests, evidence, rollback or roll-forward, documentation, coherent scope, MIT contribution rights, and third-party provenance.

The bug and proposal templates redirect vulnerability details away from public issues and prohibit credentials, tokens, personal data, private exploit details, and unrestricted signed media URLs in public evidence.
