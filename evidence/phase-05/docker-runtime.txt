FAILURE FOUND AND CORRECTED
The initial visual page was usable after a browser refetch, but the first browser suite returned 2 passed / 6 failed. Raw Node Fetch in Web returned Router 403 despite an explicit Host header. A local echo server proved Fetch sent the destination host (127.0.0.1:36517), discarding requested Host 127.0.0.1:4000. The same issue had been invisible when host-run SSR addressed loopback directly.
Added a narrow Node HTTP server transport, preserving the exact public Host/Origin with positive header selection, 16 shared request slots, bounded sockets/headers, cancellation and the existing four-second/256-KiB response boundary. No Router security policy was relaxed. Apollo caches remain request-scoped. Browser Fetch is unchanged.
The profile keyboard test also pressed Tab before the asynchronous sign-in control existed; it now waits for that control before testing tab order. The outage alert assertion is scoped to the dialog, excluding Next's route announcer. No product behavior was weakened to pass these checks.
