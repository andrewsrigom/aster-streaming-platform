# P12-R09 bounded OTLP exporter behavior

Exact source: a2015d94a0f3e2042595ead06df90b72d672ff1c

Policy

- only complete bounded HTTP(S) `/v1/metrics` endpoints without credentials,
  query, fragment, whitespace or control characters are accepted;
- the trace endpoint is derived only by replacing the final `/v1/metrics` with
  `/v1/traces`;
- metrics and traces each use exporter concurrency 1;
- trace queue size equals `maxActiveSpans` (default 128, maximum 512);
- trace export batch is at most 32;
- SDK and repository health wrappers use the configured finite export timeout;
- flush/shutdown wait for both signals to settle and return a stable result;
- exporter state never participates in service readiness or product results.
