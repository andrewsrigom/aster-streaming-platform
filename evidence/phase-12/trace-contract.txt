Implemented contract

- `@aster/telemetry` is the only owner of the OpenTelemetry trace SDK and OTLP
  trace exporter. Public packages consume repository-owned observation types.
- Fixed span names are `aster.http.server` and
  `aster.dependency.operation`; dimensions come only from exported finite sets.
- Inbound W3C `traceparent` is validated. Invalid or zero context is discarded
  and a local root is still created.
- AsyncLocalStorage scopes active context. A synchronous provider gives the
  current trace/span to the existing redacting structured logger.
- Active/retained spans default to 128 and accept only 1–512. Retention drops
  oldest complete spans and reports the finite dropped count.
- PostgreSQL, Redis, broker, object storage, owner HTTP reads and the media
  coordinator use the same dependency observation boundary.
